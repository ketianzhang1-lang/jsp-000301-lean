- Mathematical result: Jan Mycielski's 1955 construction, not a new solution.
- Formalization: independently written for this submission using Mathlib, assisted by OpenAI ChatGPT.

The official issue and pull-request records were searched before preparation,
including the bodies of batch-registration issues. No existing submission specifically
covering JSP-000843 or Mycielski's construction was found in that search.
This is a bounded public duplicate check, not a claim that no Lean implementation
exists anywhere. The available Mathlib 4.34.0 tree did not include a Mycielski module.

Third-party Lean and Mathlib dependencies retain their upstream licenses and
attribution. The original scan of Mycielski's paper was inaccessible to the
preparation browser; this package supplies the full elementary proof argument
in its own words and an independently written Lean proof.

This is a self-submission by the linked GitHub account. No reviewer identity,
professional relationship, written confirmation, award level or payment information
is invented.
